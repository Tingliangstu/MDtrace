method
~~~~~~

**Syntax**

.. code-block:: text

   method = sed

**Meaning**
   Selects the reciprocal-space observable. The supported MDtrace 1.1.0 public
   workflow is ``sed``. DSF and EELS are reserved roadmap methods and are not
   supported release workflows.

**Default**
   ``sed``.
